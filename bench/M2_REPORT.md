## 讨论（诚实标注）

1. **孤立事实的差距是构造性的**：门控写入率 ~30-50%，未写入即不可检索，召回天花板 ≈ 写入率。
   合成剧本里孤立事实与噪声结构相似、门控分不出来；真实场景中用户事实相对闲聊噪声更"惊讶"，
   且归一化前置（M1.5 改道）会提升显著性——真实差距预计小于合成测量，但 M2 不许嘴硬，记为输。
   改进方向已记录：门控加实体显著性特征 / flashbulb 集群触发补写 / dream 回放补写白天漏的埋点（M5 已具备）。
2. **组合事实反超是 λ 双路读出的实证**：参数化路由（Titans 快权重）在链式查询上优于纯向量检索——
   这正是项目立论"梯度记忆 ≠ RAG"最想看到的差分。λ 爬升幅度即其量化（种子 0：λ≈0.2-0.3 区间）。
3. **过期占比是遗忘门的直接战功**：RAG 与全上下文无遗忘机制，旧版本永远等概率混在结果里。
4. fullctx 臂的 1.0 是构造性的（窗口内必然"记得"），它的代价体现在窗口字符占用与过期污染两项，
   不在召回口径内——真实 LLM 长上下文还有"迷失中段"效应，本对拍未模拟（已记录为未来改进）。

## 结论

预先登记五项：🟢🟢 两项大胜、🟡 一项打平、✅ 一项超预期、🔴 一项方向正确幅度低估。
sidecar 的核心价值主张（**少写入 70%、过期自动遗忘、组合查询更强**）成立；
代价（**孤立一次性事实召回减半**）量化在案，缓解路径明确。
